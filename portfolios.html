Project One — OnlyFriends

OnlyFriends is a prototype social app developed using Xcode, showcasing my coding skills by allowing users to create accounts, add friends, and unlock new friends with varying rarity levels for a gamified experience

Developed collaboratively in my computer science class, this app emphasizes creativity and user engagement, featuring personalized profiles and a unique rarity system for friendships.

Project Two — Task Flow

The Slots App is a fun prototype game created in Xcode, where users spin the slots to see whether they lose or gain credits, adding excitement and an element of chance.

Developed independently in my computer science class, the app features a straightforward interface for tracking credits and provides an engaging way to enjoy the thrill of gambling without real stakes.

Project Three — Tennis Stats Tracker

Track matches, serve percentages, and rally length with clean charts and simple input after play.

Uses PWA install, client‑side only storage, and a compact data model so recording a match takes under a minute.
